# Deploy Questline 3.8

Upload `life-quest-v3.8-deploy.zip` to the root of the cloned `life-quest` repository and run the deployment command supplied with the release. The included `deploy.sh` validates the archive, preserves `.git`, replaces the static site, runs the preflight and smoke tests when Node is installed, commits `Deploy Questline v3.8.0`, and pushes `main`.

Public URL: https://jmhm-intuit.github.io/life-quest/
