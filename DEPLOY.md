## Repository root files

These files should be placed directly in the root of the `life-quest` repository:

- `.nojekyll`
- `index.html`
- `manifest.webmanifest`
- `service-worker.js`
- `icon-192.png`
- `icon-512.png`
- `version.json`

Do not upload the enclosing deploy folder itself.
