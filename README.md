# Questline 3.9

Questline is a local-first, mobile-first planner for Projects, Explorations, Tasks, Habits, and life-area Review.

- Version: `3.9.0`
- Schema: `21`
- Storage key: `questline-v3-9`
- Deployment: static GitHub Pages PWA
- Personal records: stored in the browser; JSON and Excel backups remain available

## Version 3.9 focus

- Flexible Habit rhythm planning based on period targets, planned opportunities, and actual results
- Weekly reconciliation, retroactive completion, skip, catch-up, and upcoming scheduling
- Monthly recurrence by fixed day, ordinal weekday, or manual planning
- Life-area Review with positive recognition, pace comparisons, recovery wins, and evidence-based dormancy
- Integrated positive-behavior recognition assets
- Compact visual life-area selectors instead of redundant dropdowns
- Continued support for actionable Explorations and rank-aware planning
