# Questline 3.7 User Acceptance Checklist

- [ ] Add stars to at least two Activities on the same date; both remain Starred.
- [ ] Remove one star; the other remains.
- [ ] Move a Starred Task to another date; the star follows it.
- [ ] Move a Starred Habit occurrence; the star follows it.
- [ ] Use Today → Starred to see all Starred Activities.
- [ ] Open a Task and change Importance/Urgency using visual assets.
- [ ] Open a Habit, expand More details, and set Importance.
- [ ] Leave Habit Urgency on Auto and verify the derived urgency explanation.
- [ ] Override Habit Urgency and verify Rank changes.
- [ ] Export and import JSON/Excel; stars and Habit priority settings remain.
