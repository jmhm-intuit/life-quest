# Questline 3.6 User Acceptance Checklist

- [ ] Capture text carries into a new Task.
- [ ] Closing creation without saving preserves the Capture draft.
- [ ] Successful creation clears the Capture draft.
- [ ] Add more date details reveals Start time and Due by.
- [ ] A Project shows Outcome, milestones, known Tasks, and Next Move.
- [ ] An Exploration shows Next Steps and Investigation.
- [ ] A Question can receive several linked Tasks.
- [ ] Linked Exploration Tasks appear in Today.
- [ ] A weekly Habit can be reconciled from one cycle screen.
- [ ] A monthly Habit keeps Plan next prominent.
- [ ] Batch Complete and Skip update the Habit result.
- [ ] Review opens on life areas.
- [ ] Strong Momentum celebrates high-priority movement.
- [ ] Needs Proactive Focus explains stalled records.
- [ ] Quiet by Choice suppresses an area temporarily.
- [ ] One primary and up to two secondary life areas can be saved.
- [ ] JSON and Excel exports retain the new fields.
