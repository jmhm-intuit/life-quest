# Questline 3.5 Known Limitations

- Calendar integration remains a read-only `.ics` snapshot; Questline does not edit Google or Outlook events.
- Direct OAuth calendar synchronization is not included.
- Task checklists support one level only.
- Checklist steps cannot be converted into full tasks in this release.
- Advanced recurrence rules beyond daily, weekly, and monthly Habit patterns are not included.
- Desktop Matrix drag-and-drop is an enhancement; mobile uses explicit priority controls.
- The Rank is derived from Importance and Urgency and is not separately editable.
- Physical-device behavior varies by browser, especially direct local-file opening. HTTPS/PWA deployment is recommended.
- Browser data is device- and browser-specific. Use JSON or Excel backups for manual synchronization.
