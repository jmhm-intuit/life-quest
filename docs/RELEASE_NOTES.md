# Questline 3.6.0 Release Notes

## Major changes

### Review by life area
- Review opens on an Areas view.
- Strong Momentum and Needs Proactive Focus are shown before detailed reporting.
- Evidence includes high-rank completions, Project and Exploration movement, Habit targets, recent activity, and neglected records.
- Attention Footprint avoids claiming untracked actual time.
- Quiet by Choice can suppress an area for 30 days.

### Habit Cycle Review
- Every Habit has both a review path and a planning path.
- High-frequency Habits emphasize Review cycle; monthly and low-frequency Habits emphasize Plan next.
- Recent, current, and upcoming occurrences are visible together.
- Occurrences can be completed, skipped, moved, or batch reconciled.
- Numeric Habits can be corrected from one period view.

### Actionable Exploration
- Explorations open on Next Steps and include an Investigation view.
- Questions, Experiments, and Options can contain linked Tasks.
- Tasks can be added inline and inherit Exploration context.
- A visible Next Move connects broad investigation to daily execution.
- Large grey entry cards were replaced by compact parchment investigation threads.

### Project decomposition
- Project Plan shows Outcome, overall progress, milestones, known Tasks, and Next Move.
- Project Tasks remain organized by workstream and can be added inline.

### Capture and task creation
- Capture text is preserved and prefilled in the selected creation flow.
- The draft clears only after successful creation.
- New Tasks use one Date by default.
- Add more date details reveals optional start time and separate deadline.

### Optional multiple life areas
- Projects, Explorations, Tasks, and Habits keep one primary area.
- Up to two optional secondary areas can be selected under additional details.
- Review counts global progress once and labels secondary-area shared contributions.

## Compatibility

Version 3.6 migrates Version 3.5 and earlier Questline data. Export a JSON or Excel backup before extended testing.
