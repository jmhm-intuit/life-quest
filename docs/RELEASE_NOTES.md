# Questline 3.7.0 Release Notes

Questline 3.7 adds the approved visual priority asset family and removes the one-star-per-day restriction.

## New

- Importance 1–3 visual selectors
- Urgency 1–3 visual selectors
- Rank R10–R1 visual badges and priority editor
- Multiple Starred Tasks and Habit Activities on one date
- Habit Importance and optional Urgency override in **More details**
- Automatic Habit urgency remains the default and is explained in the editor

## Compatibility

- Schema 19
- Storage key `questline-v3-7`
- Migrates Questline 3.6 and earlier local records
- Existing stars stored as a single value are migrated to an array
